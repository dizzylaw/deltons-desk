Import older trade history

Myfxbook only hands over each account's last 50 closed trades. Add everything older here, once per account, from a report saved in MetaTrader. Trades the sync already has are skipped, so nothing is counted twice.

Save a report in MetaTrader

MT4: log in to the account (the investor password is enough). In the Account History tab, right-click › All History, then right-click › Save as Detailed Report.

MT5: log in to the account. In Toolbox › History, right-click › All History (or a custom period from the start), then right-click › Report › HTML.

Reports have no magic numbers, so imported trades are grouped by EA from their trade comment, or by the names in config.js.
