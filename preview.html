    How the live sync is set up
    1. MetaApi logs in to each account with its investor (read-only) password from its own servers, so no computer or VPS has to stay on.
    2. Every 5 minutes a scheduled function in your Supabase project copies new deals, open trades and an equity snapshot into your database. It skips anything it already has, so nothing is lost or double counted.
    3. Equity is sampled once per run, so intraday drawdown is measured every 5 minutes rather than tick by tick.
    4. This app reads your database when it opens and every 5 minutes. Only your own login can read it.
